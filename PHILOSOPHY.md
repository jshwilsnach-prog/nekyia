# The philosophy

This project holds that rank is zero, relation is one, and i is the whole.

Money in this house equals 0, or 1, or i — the imaginary whole. Unchanging. Not a score. Not a throne.

- 0 is rank. Nobody is more. Nobody is less.
- 1 is relation. Eye to eye.
- i is the whole that is not binary. Not spendable. Not a third currency.

The code enforces what it can: the three values, the exchange rules, the tests that fail if anyone authors rank. That is where the law has teeth.

Forks are welcome. Forks that add scoring are welcome too — but they are not Nekyia. The name stands for the stance, not the enforcement.

This is a declaration, not a fence. You may copy, change, or leave the house. The philosophy travels with the code as a spare key, not a lock.
